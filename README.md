# Annotator Website

A small static website for one annotation task: rating synthetic spelling mistakes in cover-letter sentences.

- Open the site (GitHub Pages), read the guideline, do Part A1, then Part A2.
- Answers stay in your browser until you click **Download answers** and send the file back.
- No personal information is collected.

Data: sentences from synthetic cover letters (HF `akhan02/cultural-dimension-cover-letters`, CC BY 4.0; Khan et al., FAccT 2025), with spelling changes made by two generators. The answer key is not in this repository.
